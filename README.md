A Minecraft launcher built on clean installs, zero telemetry, and no corporate strings.

---

LuniVex is a fork of Modrinth's open-source [Theseus](https://github.com/modrinth/theseus) launcher (GPLv3), rebranded and extended with LuniVex-specific features. It uses the Modrinth API and content ecosystem while removing Modrinth branding from the user-facing UI.

## What's different

- No telemetry or analytics of any kind
- No Modrinth branding in the UI
- Essential one-click installer built into the home page
- Auto-updater built in - Windows updates silently in the background
- Syl's Picks on the Discover page - curated modpack recommendations
- Violet UI throughout

## Status

Windows - v1.0.0 releasing this week.

macOS - in progress, being handled by Arqe.
