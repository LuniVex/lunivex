# LuniVex Client logo studies

These are original SVG drafts for the client's orbital/stellar identity.
The existing app icon is still in use. The three options are:

- `orbit.svg`: a planet with an L cut into it and a tilted orbit.
- `trajectory.svg`: an open orbital path around an L.
- `nova.svg`: a stellar silhouette with the initial in its centre.

`preview.svg` compares the marks at large size and at 16, 24, 32 and 48 pixels.
`preview.png` is its rendered counterpart. The monochrome palette is for comparing
shapes; a final palette and wordmark are separate design decisions.
